# AimPrac

A first-person aim trainer built in Unity. You get **2 minutes** to hit as many targets as you can, then see how your run compares to your all-time best.

## Play it

Download the latest Windows build from the [Releases](https://github.com/KissDarius/AimPrac/releases/tag/v1.0) page, extract the whole folder, run `AimPrac.exe` and start to Practice!

## Gameplay

- Shoot the floating targets in a sci-fi arena before time runs out.
- The HUD shows your **targets hit**, your **accuracy** and the remaining time.
- When the run ends, the results screen shows your **practice statistics** next to your **highest statistics**, so there is always a score to beat.
- Your best scores are saved between sessions.

## Features

- Main menu with Practice, Options and Exit
- Options menu with volume slider and fullscreen toggle
- First-person movement and mouse look
- Weapon with recoil animation

## Controls

| Action | Input |
| --- | --- |
| Look | Mouse |
| Move | WASD |
| Shoot | Left mouse button |
